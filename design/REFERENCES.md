# 디자인 참고 자료

블로그에서 나중에 쓸 만한 외부 자료를 적어 둡니다. 당장 쓰는 것이 아니라 "이런 게 있었다" 를
잊지 않으려는 목록입니다. 실제로 가져다 쓸 때는 반드시 라이선스를 먼저 확인합니다.

## 아이콘

### koboyo 아이콘
- 주소: https://koboyo.com/icons
- 적어 둔 날: 2026-08-27
- 왜: 블로그 본문·표지 그림에 쓸 아이콘 후보로 대표님이 지목하셨습니다.
- 확인 안 된 것: **라이선스와 출처를 아직 확인하지 못했습니다.** 이 세션에 웹 접근 권한이
  없어 페이지를 열어보지 못했습니다. 쓰기 전에 상업적 이용 가능 여부와 표기 의무를 확인해야
  합니다.
- 쓸 때: SVG 로 받아 `assets/diagrams/` 에 두는 것이 지금 구조와 맞습니다. 본문에서는
  `{{svg: 이름}}` 으로 펴 넣습니다(`scripts/diagram.js`).
