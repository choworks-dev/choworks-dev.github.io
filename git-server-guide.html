codechains-macmini · LAN 전용 · Gitea 1.27.2

Windows PC에서 Git 서버에 붙기

집 안 네트워크에 있는 Mac mini Git 서버에 Windows PC를 연결하고, 원격 저장소를 만들어 클론하기까지. 위에서부터 순서대로 한 번만 하면 됩니다.

접속 정보
웹 UI
http://codechains-macmini.local:3000/
SSH 클론 주소
ssh://git@codechains-macmini.local:2222/codechains/<저장소>.git
계정
codechains — 가입은 막혀 있고 이 계정 하나만 씁니다
SSH 포트
2222 — 22번이 아닙니다
서버 IP
192.168.0.4 — DHCP라 바뀝니다. 호스트명을 쓰세요
접속 조건
192.168.0.x — 방화벽이 집 안 LAN만 허용합니다
1

서버가 보이는지 확인

Windows에서 PowerShell을 열고 이름 해석과 두 포트를 확인합니다.

PowerShell
ping codechains-macmini.local

Test-NetConnection codechains-macmini.local -Port 3000   # 웹
Test-NetConnection codechains-macmini.local -Port 2222   # SSH

둘 다 TcpTestSucceeded : True 가 나와야 다음으로 갑니다.

이름이 안 풀리면 IP로 먼저 시도해 보세요 — ping 192.168.0.4

IP는 되는데 이름만 안 되면 Windows의 mDNS가 꺼진 경우입니다. 이 문서의 주소를 전부 192.168.0.4 로 바꿔 쓰면 당장은 되지만, 서버 IP가 바뀌면 클론 주소가 깨집니다. 알려주시면 서버 쪽에서 이름 해석 경로를 열어 드리겠습니다.

2

웹 UI 로그인

브라우저에서 http://codechains-macmini.local:3000/ 를 열고 codechains 계정으로 로그인합니다. 비밀번호는 서버를 설치할 때 직접 정하신 값입니다.

비밀번호가 기억나지 않으면 서버(Mac mini)의 터미널에서 새로 정할 수 있습니다.

서버 · 리눅스 터미널
sudo -u git env USER=git HOME=/home/git GITEA_WORK_DIR=/var/lib/gitea \
  /usr/local/bin/gitea admin user change-password \
  --username codechains --password '새비밀번호' \
  --must-change-password=false -c /etc/gitea/app.ini
3

Windows에 SSH 키 만들기

이 PC 전용 키를 하나 만듭니다. 이미 id_ed25519_gitea 가 있으면 이 단계는 건너뛰세요.

PowerShell
ssh-keygen -t ed25519 -C "codechains@windows" -f "$env:USERPROFILE\.ssh\id_ed25519_gitea"

암호(passphrase)를 묻거든 그냥 Enter 두 번이면 됩니다. 집 안에서만 쓰는 키이고, 암호를 걸면 push 할 때마다 물어봅니다.

4

공개키를 서버에 등록

공개키(.pub)를 클립보드로 복사합니다. 비밀키는 절대 복사하지 마세요.

PowerShell
Get-Content "$env:USERPROFILE\.ssh\id_ed25519_gitea.pub" | Set-Clipboard

웹 UI 오른쪽 위 프로필 → 설정 → SSH / GPG 키 → 키 추가 에 붙여 넣고 저장합니다. 이름은 windows-pc 처럼 알아볼 수 있게 지으세요.

5

주소를 짧게 만들고 연결 시험

%USERPROFILE%\.ssh\config 파일에 아래 내용을 추가합니다. 파일이 없으면 새로 만드세요 — 확장자는 없습니다.

%USERPROFILE%\.ssh\config
Host gitserver
    HostName codechains-macmini.local
    Port 2222
    User git
    IdentityFile ~/.ssh/id_ed25519_gitea
    IdentitiesOnly yes

그리고 붙는지 확인합니다.

PowerShell
ssh -T gitserver

이렇게 나오면 성공입니다. 셸 접속이 안 된다는 문구는 정상이며, Git은 이 상태로 잘 동작합니다.

기대하는 응답
Hi there, codechains! You've successfully authenticated with the key
named windows-pc, but Gitea does not provide shell access.
6

원격 저장소 만들기

이 서버는 push 만으로 저장소가 자동 생성되지 않습니다. 먼저 만들어야 합니다.

방법 A — 웹 UI (권장)
오른쪽 위 + → 새 저장소. 소유자 codechains, 이름을 정하고 만들기. 새 저장소는 기본이 비공개, 기본 브랜치는 main 입니다. 처음이라면 저장소를 파일로 초기화를 켜두면 바로 클론할 수 있습니다.

방법 B — PowerShell에서 API로
웹 UI 설정 → 애플리케이션 → 액세스 토큰에서 토큰을 하나 발급받고 (권한은 write:repository), 아래처럼 만듭니다.

PowerShell
$token = "발급받은_토큰"
$body  = '{"name":"myrepo","private":true,"auto_init":true,"default_branch":"main"}'

Invoke-RestMethod -Method Post `
  -Uri "http://codechains-macmini.local:3000/api/v1/user/repos" `
  -Headers @{ Authorization = "token $token" } `
  -ContentType "application/json" -Body $body
7

클론하거나, 기존 프로젝트를 올리기

서버에 있는 저장소를 내려받을 때

PowerShell 또는 Git Bash
git clone gitserver:codechains/myrepo.git

# 5단계를 건너뛰었다면 전체 주소로도 됩니다
git clone ssh://git@codechains-macmini.local:2222/codechains/myrepo.git

Windows에 이미 있는 프로젝트를 서버로 올릴 때 — 6단계에서 저장소를 만들 때 파일로 초기화는 꺼두세요.

PowerShell 또는 Git Bash
cd C:\path\to\project
git init
git add .
git commit -m "최초 커밋"
git branch -M main
git remote add origin gitserver:codechains/myrepo.git
git push -u origin main

커밋에 이름과 메일이 안 잡혀 있으면 한 번만 설정해 두세요.

PowerShell 또는 Git Bash
git config --global user.name  "codechains"
git config --global user.email "codechains@gmail.com"

막힐 때

증상원인해결
Permission denied (publickey) 공개키가 등록되지 않았거나, Git이 다른 키를 쓰고 있음 4단계 재확인. ssh -v -T gitserver 로 어떤 키를 시도하는지 봅니다
Connection refused / 응답 없음 포트 22로 붙는 중이거나, LAN 밖에 있음 포트는 2222. 집 밖이면 방화벽이 막습니다 — 아래 참고
호스트명을 못 찾음 Windows mDNS 미동작 임시로 192.168.0.4 사용. 근본 해결은 알려 주시면 서버에서 처리
웹은 열리는데 저장소가 안 보임 새 저장소는 기본 비공개, 비로그인 조회도 차단 로그인 상태인지 확인
API가 403 을 반환 토큰 권한 부족, 또는 비밀번호 변경 대기 상태 토큰에 write:repository 부여. 그래도 안 되면 서버에서 해제 필요
repository does not exist push 만으로는 저장소가 만들어지지 않음 6단계로 먼저 생성

알아두실 것

  • SSH는 2222번입니다. 이 서버에는 일반 sshd가 없고 Gitea 내장 SSH만 돕니다. 그래서 서버 셸에는 SSH로 들어갈 수 없습니다.
  • IP가 아니라 호스트명을 쓰세요. 서버 IP는 DHCP라 바뀝니다. 호스트명으로 클론해 두면 IP가 바뀌어도 remote 주소가 깨지지 않습니다.
  • 집 밖에서는 접속되지 않습니다. 방화벽이 192.168.0.0/24 만 허용합니다. 외부에서 쓰시려면 포트포워딩 대신 Tailscale이나 WireGuard를 붙이는 편이 안전합니다 — 필요하시면 설정해 드리겠습니다.
  • 저장소는 기본 비공개, 기본 브랜치는 main 입니다.
  • push-to-create는 꺼져 있습니다. 켜두면 6단계 없이 곧바로 push 만으로 저장소가 생깁니다. 원하시면 켜 드리겠습니다.
  • 서버는 매일 백업됩니다. Gitea 덤프는 04:02, 홈 디렉터리는 02:05에 외장하드로 넘어갑니다.
